# Introdução ao PHP 7: Scripts de consola e serviços web

📘 **Aceda à documentação do curso:** [https://stahe.github.io/pt-php7-juillet-2019/](https://stahe.github.io/pt-php7-juillet-2019/)

---

Este projeto oferece uma compilação de scripts de consola em PHP 7 que ilustram diversos aspetos da linguagem e do seu ecossistema.

## Conteúdo do repositório

Os exemplos abrangem os seguintes temas:
- **Estruturas da linguagem**
- **Acesso a ficheiros**
- **Acesso a bases de dados**
- **Acesso à Internet**

## Abordagem web

A programação web é aqui abordada na perspetiva dos **serviços web**. Neste contexto, definimos um «serviço web» como qualquer aplicação que produza texto sem formatação (servidores de dados), em contraste com os servidores de páginas web que geram uma mistura de HTML, CSS e JavaScript.

### Conceitos-chave abordados
O projeto explora conceitos web fundamentais utilizados na programação tradicional:
- Protocolo HTTP
- Formatos de resposta JSON ou XML
- Gestão de sessões
- Autenticação
